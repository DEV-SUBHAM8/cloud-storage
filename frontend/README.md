# Cloud Drive Frontend (React + Vite + Tailwind)

1. Copy .env.example to .env and set VITE_SUPABASE_ANON_KEY (anon / publishable key - NOT the service_role key)
2. npm install
3. npm run dev   -> http://localhost:5173  (backend must run on http://localhost:8000)
4. Deploy: push to GitHub, import in Vercel, add the same VITE_* variables (set VITE_API_URL to your Render URL)
